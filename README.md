# АЗС Карта 40 — Android-приложение

Готовый проект Android Studio (Kotlin). Приложение открывает карту заправок
с сайта https://azs.geoportal40.ru внутри WebView — как отдельное приложение,
без адресной строки браузера, со своей иконкой и поддержкой геолокации
("показать где я на карте").

## Что внутри

- `MainActivity.kt` — WebView с включённым JavaScript, геолокацией,
  индикатором загрузки, pull-to-refresh, обработкой кнопки "Назад"
  (сначала листает историю внутри карты, потом закрывает приложение)
  и экраном "нет интернета" с кнопкой "Повторить".
- Внешние ссылки (например, номер телефона или сторонний сайт) открываются
  в системном приложении, а не внутри WebView.
- Разрешения: `INTERNET`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`.

## Как собрать APK

Есть два способа. Выберите тот, что удобнее.

### Способ 1 — без установки чего-либо на компьютер (через GitHub)

В проекте уже настроен файл `.github/workflows/build.yml`, который собирает
APK в облаке на серверах GitHub.

1. Создайте бесплатный аккаунт на https://github.com, если его ещё нет.
2. Создайте новый пустой репозиторий (Public или Private — не важно),
   например `azs-map`.
3. Загрузите туда содержимое этой папки — проще всего через веб-интерфейс:
   на странице репозитория нажмите **Add file → Upload files** и перетащите
   всё содержимое папки `AzsMap` (включая скрытую папку `.github`).
   Нажмите **Commit changes**.
4. Откройте вкладку **Actions** в репозитории — сборка запустится
   автоматически (займёт 2-4 минуты).
5. Когда сборка завершится (зелёная галочка), откройте её и в самом низу,
   в разделе **Artifacts**, скачайте `AzsMap-debug-apk` — это zip-архив
   с готовым `app-debug.apk` внутри.
6. Перекиньте `app-debug.apk` на телефон и установите (при запросе
   разрешите установку из неизвестных источников).

### Способ 2 — через Android Studio на своём компьютере

1. Установите **Android Studio**: https://developer.android.com/studio
2. Откройте эту папку (`AzsMap`) через **File → Open** в Android Studio.
3. Android Studio предложит настроить Gradle wrapper — согласитесь
   (или просто дождитесь автосинхронизации; нужен интернет, скачаются
   необходимые компоненты при первом запуске).
4. Подключите телефон по USB (включите "Отладку по USB" в настройках
   разработчика) или запустите эмулятор, затем нажмите зелёную кнопку
   **Run ▶** — приложение соберётся и установится само.
5. Чтобы получить файл APK отдельно: `Build → Build Bundle(s) / APK(s) →
   Build APK(s)`. Готовый файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.

## Возможные доработки

- **Заменить иконку** — сейчас это простая иконка-«капля топлива» в зелёном
  круге (`app/src/main/res/drawable/ic_launcher_foreground.xml`). Можно
  сгенерировать свою через Android Studio: правый клик на `res` →
  `New → Image Asset`.
- **Публикация в Google Play** потребует подписанный release-сборки
  (`Build → Generate Signed Bundle / APK`) и аккаунт разработчика Google Play.
- Сайт — одностраничное JS-приложение без открытого API, поэтому карта
  встроена как веб-страница, а не как нативная Google/Yandex Maps карта
  с маркерами. Если у геопортала есть публичный REST/WFS-эндпоинт для
  выгрузки списка АЗС, можно доработать приложение до полностью нативной
  карты — напишите, если такой эндпоинт есть, и я это добавлю.
